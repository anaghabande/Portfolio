# Anagha Bande: Professional Portfolio

A responsive, dependency-free portfolio focused on operations, supply chain, analytics, and global strategy.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static file server.

## Structure

- `index.html` : semantic content and page structure
- `styles.css` : design system, responsive layout, motion, and print styles
- `script.js` : mobile navigation, active section state, and restrained reveal effects
- `AAB_Resume_Sept2026.docx` : downloadable résumé

The site uses no external fonts, packages, frameworks, or analytics.
